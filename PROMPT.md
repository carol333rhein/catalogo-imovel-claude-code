# O prompt para colar no Claude Code

Abra o Claude Code, copie o texto do quadro abaixo e cole. É só isso: o Claude Code pergunta o resto.

```
Cria o catálogo do meu imóvel para mim. O kit é o arquivo catalogo-imovel-claude-code-main.zip.

Antes de tudo: ignora qualquer pasta de projeto que já esteja aberta ou que já exista aqui. Não mexe nela. Cria uma pasta nova chamada catalogo-imovel e trabalha só nela.

1. Procura o zip primeiro na minha pasta Downloads. Se não estiver lá, baixa de https://github.com/carol333rhein/catalogo-imovel-claude-code/archive/refs/heads/main.zip
2. Descompacta na pasta catalogo-imovel.
3. Abre o CLAUDE.md que está dentro e segue os passos de lá. Eu não sei programar, então me explica em português simples o que você está fazendo e me avisa quando eu precisar clicar em Permitir.
4. Me pergunta o título do vídeo, a palavra que as pessoas vão comentar e os dados do meu imóvel, e pede as fotos. Não inventa nada.
```

**Antes de postar:** confira os dados do imóvel e as fotos no vídeo. Se as fotos forem criadas por IA, avise no vídeo que o imóvel é ilustrativo.
