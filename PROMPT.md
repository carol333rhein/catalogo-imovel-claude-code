# O prompt para colar no Claude Code

Abra o Claude Code, copie o texto do quadro abaixo, complete o **título** e a **palavra** entre aspas, e cole.

```
Baixe o kit do catálogo de imóvel neste link, numa pasta nova, e siga as instruções do arquivo CLAUDE.md que está dentro dele para criar o catálogo do meu imóvel:
https://github.com/carol333rhein/catalogo-imovel-claude-code/archive/refs/heads/main.zip

TÍTULO DO VÍDEO (escreva o seu aqui): "ESCREVA AQUI O SEU TÍTULO"
PALAVRA DO COMENTÁRIO (escreva a sua aqui): "ESCREVA AQUI A SUA PALAVRA"

Me pergunte os dados do imóvel e peça as fotos. Não invente nada.
```

**Antes de postar:** confira os dados do imóvel e as fotos no vídeo. Se as fotos forem criadas por IA, avise no vídeo que o imóvel é ilustrativo.
