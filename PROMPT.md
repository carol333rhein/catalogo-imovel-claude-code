# O prompt para colar no Claude Code

Coloque o kit (o arquivo .zip) numa pasta, abra o Claude Code nessa pasta, copie o texto do quadro abaixo, complete o **título** e a **palavra** entre aspas, e cole.

```
Nesta pasta está o kit do catálogo de imóvel, em um arquivo .zip. Descompacte, leia o CLAUDE.md que está dentro e crie o catálogo do meu imóvel seguindo as instruções dele. Trabalhe dentro da pasta descompactada.

TÍTULO DO VÍDEO (complete aqui): "ESCREVA AQUI O SEU TÍTULO"
PALAVRA DO COMENTÁRIO (complete aqui): "ESCREVA AQUI A SUA PALAVRA"

Me pergunte os dados do imóvel e peça as fotos. Não invente nenhum dado.
```

**Antes de postar:** confira os dados do imóvel e as fotos no vídeo. Se as fotos forem criadas por IA, avise no vídeo que o imóvel é ilustrativo.
