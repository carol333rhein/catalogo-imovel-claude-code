# O prompt para colar no Claude Code

Abra o Claude Code, copie o texto do quadro abaixo, escreva o seu **título** e a sua **palavra** entre aspas, e cole. É só isso.

```
Cria o catálogo do meu imóvel para mim. O kit é o arquivo catalogo-imovel-claude-code-main.zip, que traz tudo pronto.

Antes de tudo: ignora qualquer pasta de projeto que já esteja aberta ou que já exista aqui (como uma pasta de código ou de outro trabalho). Não mexe nela nem pede para ler ela. Cria uma pasta nova chamada catalogo-imovel e trabalha só nela.

1. Procura o catalogo-imovel-claude-code-main.zip primeiro na minha pasta Downloads. Se não estiver lá, baixa de https://github.com/carol333rhein/catalogo-imovel-claude-code/archive/refs/heads/main.zip
2. Descompacta dentro da pasta catalogo-imovel.
3. Abre o arquivo CLAUDE.md que está dentro e segue os passos de lá. Eu não sei programar, então me explica em português simples o que você está fazendo e me avisa quando eu precisar clicar em Permitir.
4. Me pergunta os dados do meu imóvel e pede as fotos. Não inventa nada.

TÍTULO DO VÍDEO (escreve o seu aqui): "ESCREVA AQUI O SEU TÍTULO"
PALAVRA DO COMENTÁRIO (escreve a sua aqui): "ESCREVA AQUI A SUA PALAVRA"
```

**Antes de postar:** confira os dados do imóvel e as fotos no vídeo. Se as fotos forem criadas por IA, avise no vídeo que o imóvel é ilustrativo.
